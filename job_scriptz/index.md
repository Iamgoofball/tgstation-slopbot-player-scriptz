# job_scriptz/

Job-specific scripts, one sub-directory per tgstation job, named after the
job's slug (`medical-doctor`, `station-engineer`, ...). Each script carries
the standard safety prelude (`common/watch_prelude.py` + `precheck()`) and
the end-check footer, like every other scriptz script.

Conventions:
- **Generic first**: a job script must reuse `generic_scriptz/`, `machines/`,
  `medical/`, `engineering/`, `service/`, `movement/`, `inventory/` parts
  where they exist — only the job's own machines/consoles live here.
- **Args, never hard-code**: machine ids change every round; pass names/ids as
  args. One round's ids in comments only as examples.
- The master table below lists every job covered, its scripts and what each
  does. Grow the table in the same commit as the scripts.
